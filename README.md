# Miguel Nascimento | Portfolio

My personal portfolio website, built to showcase my projects, development skills, and learning journey as a developer.

## About the Project

This portfolio presents my projects, the technologies I use, and my progress as I continue learning and building software. It features a minimalist, dark aesthetic focused on readability, functionality, and a clean user experience.

## Features

- **About Me:** An introduction to my development journey.
- **Project Showcase:** A section displaying my projects and descriptions.
- **Interactive Elements:** JavaScript-powered interactions for navigation and user experience.
- **Responsive Design:** A layout designed to adapt to different screen sizes.
- **Contact Section:** A way for visitors to connect with me.

## Technologies and Languages

- HTML5
- CSS3
- JavaScript

## Libraries and Frameworks

The project uses vanilla JavaScript and standard web technologies, without requiring a frontend framework.

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor, such as [Visual Studio Code](https://code.visualstudio.com/).
- A local development server, such as the Live Server extension.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/m1guel-py/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_DIRECTORY
   ```

3. Open the project in your code editor.
4. Start a local development server and open the website in your browser.

## Usage

Open the website through your local development server or visit the deployed version.

Explore the different sections to learn about me, browse my projects, and discover the technologies used in their development.

## Testing

Testing is performed manually during development.

- **Functionality Testing:** Checking navigation, interactive elements, and project display.
- **Debugging:** Identifying and correcting HTML, CSS, and JavaScript issues.
- **Responsive Testing:** Checking the layout at different screen sizes.
